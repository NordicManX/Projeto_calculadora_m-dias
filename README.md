# Calculadora Simples

Esta é uma calculadora simples desenvolvida com HTML, CSS e JavaScript. O projeto é uma ótima maneira de aprender sobre a manipulação de DOM, eventos e estilos em uma aplicação web.

## Funcionalidades

- Realizar operações básicas: adição, subtração, multiplicação e divisão.
- Interface amigável e responsiva.
- Suporte a entrada de números decimais.

## Tecnologias Usadas

- **HTML**: Estrutura básica da página.
- **CSS**: Estilização e layout.
- **JavaScript**: Lógica da calculadora e manipulação de eventos.
